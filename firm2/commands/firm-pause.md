# /firm-pause — пауза и возобновление сборки

Аргументы `$ARGUMENTS`: пусто — поставить паузу; `resume` — снять; `status` — проверить.

```bash
ENGINE="$(node "${CLAUDE_PLUGIN_ROOT}/scripts/engine-root.mjs")"
```

## Поставить паузу

```bash
node "$ENGINE/scripts/firm-state.mjs" pause --reason "<словами, почему>" --json
```

Скажи человеку вслух, что происходит дальше, — это не аварийная остановка:

- **задачи в работе доводятся до конца** вместе со слиянием. Бросать их на полуслове
  значило бы оставить грязные рабочие деревья и недописанные события;
- **новые задачи не берутся**: планировщик спрашивает про паузу перед каждым запуском;
- прогон завершится сам, вернув список незапущенных задач. Отдельно гасить его не нужно.

Ждать окончания в этой сессии не обязательно — состояние живёт в журнале, а не в сессии.

Обе команды дописывают в журнал границу паузы (`lifecycle/paused` и `lifecycle/resumed`,
`ticket: MR`), и это не бухгалтерия: время, когда прогон стоял, вычитается из ожидания
движка на доске. Иначе остановку, которую сделал человек, замер предъявлял бы прогону
(ADR-0009). Поэтому `--reason` стоит писать словами: по нему потом и читают, почему стояли.
Если в ответе `journaled: false` — событие записать не удалось, пауза при этом поставлена;
скажи это человеку: время этой паузы уйдёт в ожидание движка.

## Снять паузу и продолжить

```bash
node "$ENGINE/scripts/firm-state.mjs" resume --json
```

Дальше обычный `/firm-build` в **новой** сессии. Заново уже влитые задачи он не возьмёт:
список задач строится из журнала событий, а `merged` из него исключены.

Задачи, которые успели начаться, но не дошли до слияния, пойдут с начала — но в своём
рабочем дереве, где их прошлая работа уже лежит. Стадиям сказано продолжать начатое,
а не писать поверх.

## Проверить

```bash
node "$ENGINE/scripts/firm-state.mjs" paused --json
```

## Где живёт флаг

`.firm/current/pause.json` — каталог уже в `.gitignore`. Это состояние одного прогона на
одной машине, в репозитории ему не место: иначе пауза, поставленная здесь, остановила бы
сборку у любого, кто заберёт ветку.

## Инварианты

- Пауза не отменяет и не откатывает сделанное. Всё, что влито, остаётся влитым.
- Пауза не заменяет остановку: если нужно оборвать прогон немедленно, это `/workflows`
  и ручная остановка, с последующим разбором грязных деревьев.
