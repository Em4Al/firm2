# ADR-0001. Истина по задачам — файлы репозитория; доска только на чтение

- Статус: принято
- Дата: 2026-09-21
- Контекст: проектирование маршрута `firm2`

## Контекст

Маршрут требует реестра задач, из которого строятся: дашборд статусов, граф
зависимостей, правило эпика, выбор задач для параллельного запуска и статистика
времени. Нужен ровно один источник истины, иначе источники разойдутся.

Рассматривались три варианта:

1. Файлы в репозитории — задача есть markdown-файл с frontmatter.
2. Issues и эпики трекера (GitHub Projects, GitLab) как истина.
3. Гибрид с двусторонней синхронизацией: карточку можно двигать на доске, и это
   меняет файл.

## Решение

**Истина — файлы репозитория.** Задача это
`openspec/changes/<change>/tasks/T-XXX.md` с frontmatter. Доска, если она
появится, строится из файлов односторонне и доступна **только на чтение**.

Первая реализация доски — генерируемый HTML-дашборд. Зеркалирование в GitHub
Projects возможно позже поверх того же генератора, но остаётся односторонним:
репозиторий → доска.

## Обоснование

Инвариант движка «всё состояние в репозитории» уже действовал в предыдущей
версии и оправдал себя. Кроме того:

- Переходы статусов пишутся локально, без сети и токенов. Сетевой вызов на
  каждом переходе может молча упасть, и тогда статистика окажется дырявой ровно
  там, где сеть моргнула.
- Маршрут остаётся независимым от хостинга: GitHub и GitLab поддерживаются
  одинаково, а переезд между ними не трогает реестр задач.
- История переходов бесплатно лежит в git.
- Задачи и спеки живут рядом и ревьюятся одним диффом.

Двусторонняя синхронизация отвергнута жёстко: две пишущие стороны при
параллельной разработке в нескольких worktree неизбежно разойдутся, и человек
перестанет доверять обеим. Потеря доверия к реестру дороже удобства
перетаскивания карточек.

## Следствия

- Дашборд — производная от файлов и событий, а не самостоятельное хранилище
  (см. ADR-0003).
- Переезд на GitHub не меняет реестр; движок остаётся host-agnostic.
- Перетащить карточку мышью нельзя — изменение статуса возможно только через
  событие. Это осознанная цена детерминизма (см. ADR-0002).
