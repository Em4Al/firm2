# firm-tdd (адаптер)

Приём движка для **тест-ориентированной разработки**.

**Реализация:** делегирует в `mattpocock-skills:tdd` (пин версии — см. `.firm/config`).
Вызови Skill tool со скиллом `mattpocock-skills:tdd`.

> Точка изоляции зависимости — см. ADR-0011 (`docs/adr/0011-приём-изолирует-внешний-скил.md`).
