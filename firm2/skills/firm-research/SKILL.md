# firm-research (адаптер)

Приём движка для **проверки внешних фактов** по высокодоверенным источникам.

**Реализация:** делегирует в `mattpocock-skills:research` (пин версии — см. `.firm/config`).
Вызови Skill tool со скиллом `mattpocock-skills:research`.

**Когда:** research-тикеты; а также Ревьюер-QA — только для тикетов с меткой `факточувствительный`.

> Точка изоляции зависимости — см. ADR-0011 (`docs/adr/0011-приём-изолирует-внешний-скил.md`).
